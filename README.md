# Date Invitation

A single-page interactive date invitation website.

## Deploy

### GitHub Pages
Upload the contents of this folder to a GitHub repository. In **Settings → Pages**, choose **Deploy from a branch**, select `main` and `/ (root)`. GitHub Pages will use `index.html` as the entry point.

### Vercel
Import this repository into Vercel. No build command is required; Vercel can serve the static `index.html` directly.
